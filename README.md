 Tabsviews – Communication System Assignment
 Project Description
This project is developed as part of a Vibe Coding assignment to demonstrate building a small full-stack application in a limited time.

The application simulates a *communication system* that handles:
- Emails
- SMS
- WhatsApp messages

No real messages are sent. All actions are stored in the database and displayed in tab-based list views.

---

 Tech Stack
- Java
- Spring Boot
- Spring Data JPA (Hibernate)
- Maven
- H2 / MySQL Database
- HTML, CSS, JavaScript (Frontend)

---

## 📑 Features

### 🔹 Tabs with List Views
- *Email Tab*
  - Serial Number
  - Email Sent To
  - Timestamp

- *SMS Tab*
  - Serial Number
  - Mobile Number
  - Message Sent
  - Timestamp

- *WhatsApp Tab*
  - Serial Number
  - Mobile Number
  - Message Sent
  - Timestamp

---

### 🔹 Forms
- Send Email
- Send SMS
- Send WhatsApp

On clicking *Submit*:
- Data is saved into the database
- Corresponding tab list view is updated
